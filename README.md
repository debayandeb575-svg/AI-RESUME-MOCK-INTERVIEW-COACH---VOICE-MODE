
# AI Resume Mock Interview Coach - Voice Mode 🎙️

An AI-powered mock interviewer that analyzes your resume and conducts voice-based interviews to prepare you for real placements.

### 🚀 Problem Statement
Students have good resumes but fail in interviews due to lack of practice and real-time feedback. Existing tools are text-only and boring.

### 💡 Solution
This app:
- Parses your uploaded Resume (PDF)
- Generates personalized interview questions using LLM
- Conducts interview in VOICE mode (Speech-to-Text + Text-to-Speech)
- Gives instant feedback, scoring, and improvement tips
- Covers Technical, HR, and Project-based questions

### ✨ Features
- 📄 Resume Parsing (PDF)
- 🎤 Voice Interaction - Speak your answers
- 🤖 AI-generated contextual questions
- 📊 Real-time feedback & scoring
- 🔄 Follow-up questions based on your answers

### 🛠️ Tech Stack
- **Frontend:** Streamlit
- **AI:** OpenAI / Gemini API, LangChain
- **Voice:** SpeechRecognition, pyttsx3 / gTTS, WebRTC
- **Resume Parser:** PyMuPDF / pdfminer
- **Language:** Python
